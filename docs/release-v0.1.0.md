WheelFix 0.1.0 is the first public release of the lightweight Windows mouse
wheel debounce filter.

### Highlights

- Filters short opposite-direction pulses from worn mechanical wheel encoders.
- Adjustable 10–150 ms window with Light, Balanced and Strong presets.
- Runs in the Windows notification area and can start with the current user.
- English and Italian interface selected automatically from Windows.
- Portable, dependency-free, open source and free from telemetry or networking.

Download `WheelFix-v0.1.0-windows.zip`, extract it and run `WheelFix.exe`.
Start with **Balanced (55 ms)**.

The executable is not code-signed, so Windows may show a reputation warning on
first launch. See the README for Raw Input limitations and build instructions.
